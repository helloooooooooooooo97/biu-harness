# 52-capstone 讲义

## 目标

- 用 53 课学到的全部能力完成一个**结业项目**（三选一）。
- 学会"验收自己的项目"：跑通、有测试、有文档。

## 三选一

**A. 编码 agent**：让你的 mini-dsh 实际完成一个真实编码任务（读仓库、改代码、跑测试）。

**B. 自动化服务**：用 JSON-RPC 入口（第 40 课）做一个可被外部程序驱动的服务（Python/编辑器插件调用）。

**C. 自修改 UI**：实现第 43 课的动态插件——agent 写一个带 UI 的插件，经审批热挂载到前端。

## 验收标准（三条通用）

1. **能跑**：`npm start` 或等价命令一键启动；
2. **有测试**：关键路径有测试覆盖；
3. **有文档**：README 说明"这是什么、怎么跑、架构怎么分"。

## 本课代码

`capstone-starter.ts` 提供一个小骨架：`CapstoneHarness`（mock LLM + 工具 + JSON-RPC 的最小整合），你可以从它出发扩展。

## 提示

- 复用 `project/` 的包（llm/session/tools/loop）；
- 用第 53 课 benchmark 验证你的成果不是"只能跑一次"。

## 小结

结业 = 把学过的机制**组合**成一个能用的东西，并证明它可用。
