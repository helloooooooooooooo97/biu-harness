# 第一周任务 prompt 集

> 每个任务都先用 Web UI 跑一遍，再用 `--profile headless` 跑一遍，最后填观察模板。

## 1. 环境探测（必做）

```text
查看当前目录，列出里面有哪些文件和文件夹，并逐个说明它们的用途。
```

看点：agent 会调用几次工具、是否读了文件内容、回答是否准确。

## 2. 文件读写

```text
读取当前目录下的 README.md（或任意一个文件），用三句话总结它的内容，
然后把总结写入 summary.md。
```

看点：读与写是否分开两个工具调用；写之前有没有读文件（read-before-write）。

## 3. 写脚本并运行

```text
写一个 Node.js 脚本，计算 1 到 100 的和并打印结果；保存为 sum.js 并用 bash 运行它。
```

看点：模型是否先写文件再执行；输出是否符合预期。

## 4. 追问澄清

```text
我现在在做一个「番茄钟」命令行工具，你打算怎么设计它的文件结构？
先不要写代码，给我一个方案。
```

看点：无工具调用的纯对话回合，观察 turn 是否只包含一个 step。

## 5. 综合任务

```text
统计当前目录下所有 .md 文件的总行数，并按文件列出；把结果写入 lines.md。
```

看点：多文件遍历、多次工具调用、最终写入——一个典型的"多 step turn"。
